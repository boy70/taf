## 💡 Smart Design Decisions

### Why Book Guide?
- Premium feel vs boring modal
- Non-corporate, friendly approach
- Builds confidence before starting
- Teaches SWOT/SMART concepts clearly
- 3D entrance feels special

### Why SWOT + SMART?
- Proven business frameworks
- Gets employee to think strategically
- Gives HR structured data to analyze
- Separates "analysis" from "goals"
- Easy to understand with right explanation

### Why Color Coding?
- Visual scanning (instant recognition)
- Matches traditional SWOT colors
- Non-ambiguous sections
- Helps with navigation

### Why Auto-Opening?
- First-time users get guided
- Removes friction
- Builds confidence
- Only once (doesn't annoy repeat users)

### Why Structured Data?
- HR can analyze proposals systematically
- Better decision making
- Can identify patterns
- Enables future features (analytics, recommendations)

## 🎨 Design System

### Colors:
```
Primary Gradient: Blue → Indigo
SWOT: Green, Yellow, Blue, Red
SMART: Indigo (consistent)
Guide Headers: Blue → Green → Purple → Amber
Text: Gray (900-700-600)
```

### Typography:
```
Headers: 3-5xl, font-black
Labels: sm, font-bold
Body: base, regular
Small: xs, regular
Helper: xs, italic
```

### Spacing:
```
Sections: py-8, px-8
Cards: p-6, md:p-8
Gaps: gap-4, md:gap-6
Margins: mb-4, mb-6
```

### Animations:
```
Book: rotateY, spring physics, 300ms
Pages: rotateZ, opacity, stagger, 400ms
Buttons: scale, tap feedback, 200ms
Floats: rotate, continuous, 15-20s
```
