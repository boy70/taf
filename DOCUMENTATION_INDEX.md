## 🚀 Quick Start

### For Testing:
1. Go to Employee Dashboard
2. Click "New Proposal"
3. 📖 Guide opens automatically (first time only)
4. Read through 4 pages
5. Click "Start Creating 🚀"
6. Fill SWOT + SMART sections
7. Submit proposal
8. Check HR dashboard to review

### For HR Review:
1. Go to HR Dashboard
2. Visit Proposal Review Center
3. See statistics
4. Filter by status
5. Click "Review" on any proposal
6. See SWOT + SMART data
7. Add feedback
8. Approve/Reject
