## 🎯 Key Concepts Explained

### Director
A person assigned by HR to oversee and manage a project, event, or team. Gets full access and visibility.

### Resource
A project, event, or team that can have directors assigned.

### Directorships
The relationship/assignment of a director to a resource.

### Roles
Different authority levels: DIRECTOR, CO_DIRECTOR, LEAD

### APIs
```
GET  /api/directors                    # View all (HR)
POST /api/directors                    # Bulk assign (HR)
GET  /api/directors/me                 # My assignments
GET  /api/projects/[id]/directors
POST /api/projects/[id]/directors      # Assign (HR)
DELETE /api/projects/[id]/directors    # Remove (HR)
GET  /api/events/[id]/directors
POST /api/events/[id]/directors        # Assign (HR)
DELETE /api/events/[id]/directors      # Remove (HR)
GET  /api/teams/[id]/directors
```
