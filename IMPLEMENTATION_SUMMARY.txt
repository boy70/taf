FEATURE OVERVIEW
================================================================================

This comprehensive feature adds organization profile management and event 
discovery capabilities to your Tafsula platform. It enables:

1. HR managers to create professional organization profiles
2. Organizations to publish posts and updates
3. Users to discover and register for events and training sessions
4. Public organization directory
5. Public events discovery and registration system

================================================================================
NEW DATABASE MODELS
================================================================================

1. startupProfile
   - Stores organization profile information
   - Fields: profile image, cover image, bio, contact info, location, website
   - Includes visibility control (public/private)
   - One-to-one relationship with startup

2. organizationPost
   - Stores blog posts/updates from organizations
   - Fields: title, content, image, author, status (published/draft)
   - Associated with startup and user (author)

3. eventRegistration
   - Tracks user registrations for events
   - Fields: event reference, user reference, status, registration date
   - Unique constraint on event + user combination

Model Relationships:
- startup → startupProfile (1:1)
- startup → organizationPost (1:many)
- user → organizationPost (many:1 for author)
- event → eventRegistration (1:many)
- user → eventRegistration (1:many)

Database Migration: "add_organization_profiles"

AUTHORIZATION & SECURITY
================================================================================

Role-Based Access Control:

SUPERADMIN:
- View all organizations
- Edit any organization profile
- Create posts for any organization
- View all event registrations

HR Manager:
- View their own organization profile
- Edit their own organization profile
- Create posts for their organization
- View their organization's event registrations

EMPLOYEE / REGULAR_USER:
- View public organization profiles
- View published posts
- Register for public events
- View their own registrations

Guest (Not Authenticated):
- View public organization profiles
- View published posts
- View public events
- Cannot register (redirected to login)

Security Measures:
- Session validation on all protected routes
- User role verification
- Startup ID verification for HR managers
- One-click registration prevents duplicates (unique constraint)

================================================================================
AUTHENTICATION FLOWS
================================================================================

Organization Profile Edit:
1. User navigates to /dashboard/hr/organization
2. System checks if user is HR (if not, shows error)
3. System checks if user has startupId (if not, shows error)
4. Loads existing profile data
5. User edits form and clicks Save
6. Form data sent to API with authentication token
7. API validates user is HR for that startup
8. API upserts profile (creates if not exists, updates if does)
9. Success toast shown, page refreshes

Event Registration:
1. User clicks "Register" on event
2. Session checked (not authenticated = redirect to login)
3. POST request sent to /api/events/:eventId/register
4. API checks for existing registration
5. If exists: return error (already registered)
6. If not exists: create registration with "registered" status
7. Return confirmation to user
8. Event registration count updates

Organization Discovery:
1. User navigates to /organizations
2. Fetches public organizations via API
3. API returns paginated results
4. User can search, filter, and paginate
5. Clicking organization card navigates to profile
6. Profile page shows full organization information
