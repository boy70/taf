================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: Organizations not showing in directory
Solution: 
- Ensure organization profile exists
- Check `isPublic` is set to `true`
- Verify you're using a startup with an HR manager

Issue: "Unauthorized" error when editing profile
Solution:
- Make sure you're logged in as HR for that organization
- Verify your user has role "HR" (not "EMPLOYEE")
- Check you're accessing your own startup's profile

Issue: Events not appearing
Solution:
- Check event `startAt` is in the future
- Ensure organization has public profile
- Verify event `visibility` is set to "ORG"

Issue: Images not displaying
Solution:
- Ensure image URLs are complete (include http/https)
- Check image URLs are publicly accessible
- Try a different image URL if one fails

Issue: Registration not working
Solution:
- Make sure you're logged in
- Check browser console for errors
- Verify event exists and is public
- Ensure you haven't already registered
